Oficina Prática de Estruturação e Manipulação em MySQL (DDL e DML)

Prática intensiva de criação de esquemas relacionais, integridade referencial com chaves estrangeiras duplas, evolução de esquema com ALTER TABLE, operações DML seguras e análise comparativa entre TRUNCATE e DELETE.

1. Integridade Referencial: Tabelas Pai vs. Tabelas Filhas

Em sistemas comerciais reais, as tabelas não existem de forma isolada. A tabela produtos depende diretamente da existência prévia de categorias e fornecedores para ser criada e receber registros.

Topologia de Dependência Estrutural

📁 categorias (Pai 1)
id_categoria (PK)
➔
📦 produtos (Filha)
id_produto (PK), id_categoria (FK), id_fornecedor (FK)
⬅
🏭 fornecedores (Pai 2)
id_fornecedor (PK)
Ordem de Execução Mandatória: Ao construir ou restaurar um banco de dados relacional, as tabelas independentes (pais) devem sempre ser criadas e populadas antes das tabelas dependentes (filhas).

2. Laboratório DDL: Construção Estruturada do Banco

Acesse a aba SQL do phpMyAdmin para construir a base db_laboratorio_pratico:

SQL • Estrutura de DDL com Duas Chaves Estrangeiras MySQL 
SET NAMES utf8mb4;

DROP DATABASE IF EXISTS db_laboratorio_pratico;
CREATE DATABASE db_laboratorio_pratico 
  CHARACTER SET utf8mb4 
  COLLATE utf8mb4_unicode_ci;

USE db_laboratorio_pratico;

-- Tabela Pai 1: Categorias
CREATE TABLE categorias (
    id_categoria INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(80) NOT NULL UNIQUE,
    descricao VARCHAR(200)
) ENGINE=InnoDB;

-- Tabela Pai 2: Fornecedores
CREATE TABLE fornecedores (
    id_fornecedor INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    razao_social VARCHAR(120) NOT NULL UNIQUE,
    cidade VARCHAR(80) NOT NULL,
    estado CHAR(2) NOT NULL DEFAULT 'SP'
) ENGINE=InnoDB;

-- Tabela Filha: Produtos
CREATE TABLE produtos (
    id_produto INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(120) NOT NULL,
    preco DECIMAL(10,2) NOT NULL,
    estoque INT NOT NULL DEFAULT 0,
    id_categoria INT UNSIGNED NOT NULL,
    id_fornecedor INT UNSIGNED NOT NULL,
    CONSTRAINT fk_categoria_prod FOREIGN KEY (id_categoria) REFERENCES categorias(id_categoria),
    CONSTRAINT fk_fornecedor_prod FOREIGN KEY (id_fornecedor) REFERENCES fornecedores(id_fornecedor)
) ENGINE=InnoDB;

3. Evolução Estrutural (ALTER TABLE) e Povoamento (DML)

Modificando a Tabela sem Recriá-la

SQL • Comandos de Evolução Estrutural MySQL 
-- Adicionar coluna de avaliação com validação CHECK
ALTER TABLE produtos 
ADD COLUMN avaliacao DECIMAL(3,1) CHECK (avaliacao BETWEEN 0.0 AND 10.0);

-- Modificar tamanho e valor default
ALTER TABLE fornecedores 
MODIFY COLUMN cidade VARCHAR(100) DEFAULT 'Não Informada';

Povoamento e Atualizações Direcionadas (DML)

SQL • Inserções e Updates Seguros MySQL 
-- 1. Povoando categorias e fornecedores
INSERT INTO categorias (nome, descricao) VALUES 
('Hardware', 'Componentes físicos e periféricos'),
('Acessórios', 'Cabos e suportes');

INSERT INTO fornecedores (razao_social, cidade, estado) VALUES 
('Tech Distribuidora SP', 'São Paulo', 'SP'),
('Sul Componentes', 'Curitiba', 'PR');

-- 2. Povoando produtos vinculados
INSERT INTO produtos (nome, preco, estoque, id_categoria, id_fornecedor, avaliacao) VALUES 
('Teclado Mecânico RGB', 280.00, 15, 1, 1, 9.5),
('Mouse Sem Fio 1600DPI', 95.00, 30, 2, 1, 8.8),
('Monitor 27 Pol 144Hz', 1250.00, 8, 1, 2, 9.8);

-- 3. Atualização com filtro WHERE obrigatório
UPDATE produtos 
SET preco = 269.90, estoque = 12 
WHERE id_produto = 1;

4. Comparativo de Bancada: TRUNCATE vs. DELETE

Característica DELETE (DML) TRUNCATE (DDL)
Categoria de Comando DML (Manipulação de Dados). DDL (Definição / Estrutura).
Uso de Filtro WHERE Suporta filtro por linha (ex: WHERE id = 2). Não suporta (apaga a tabela inteira instantaneamente).
Contador AUTO_INCREMENT Mantém a sequência do último ID gerado. Reseta o contador para 1.
Velocidade de Execução Mais lento em bases grandes (apaga linha por linha). Ultra-rápido (desaloca as páginas do disco).
Cuidado Absoluto com Comandos sem WHERE: Nunca execute UPDATE ou DELETE em ambiente de produção sem a cláusula WHERE!
