2. As Três Formas Normais (1FN, 2FN e 3FN)

A Normalização é o controle de qualidade do banco de dados relacional. Seu objetivo primordial é eliminar redundâncias que causam anomalias de inserção, atualização e exclusão.

1ª Forma Normal (1FN)
Atomicidade dos Valores

Regra: Cada célula deve conter um valor único e indivisível. Proibido agrupar múltiplos telefones ou itens separados por vírgula na mesma coluna.

Solução: Criar linhas separadas ou uma tabela vinculada telefones_cliente com FK.
2ª Forma Normal (2FN)
Dependência Total da Chave

Regra: Exige a 1FN. Em tabelas com Chave Primária composta, todo atributo não-chave deve depender de toda a chave primária, e não de apenas uma parte dela.

Solução: Mover o nome do produto de itens_pedido para a tabela produtos.
3ª Forma Normal (3FN)
Fim das Dependências Transitivas

Regra: Exige a 2FN. Nenhum atributo não-chave pode depender de outro atributo não-chave (dependência indireta).

Solução: Se cidade e estado dependem do cep, o endereço deve ser desacoplado.

3. Primeiro Acesso e Navegação no phpMyAdmin

O phpMyAdmin é uma ferramenta web de interface gráfica que nos permite interagir com o servidor de banco de dados MySQL de forma visual e intuitiva.

  1. Acesso ao Servidor no Navegador
    Abra o navegador no laboratório e acesse a URL local indicada pelo professor Haroldo Curti.
  2. Login com Credenciais Individuais
    Insira seu usuário e senha individuais. No menu lateral esquerdo, localize a base de dados pessoal pré-criada para você.
  3. Reconhecimento das Abas Principais
    • Aba Estrutura: Visualiza as tabelas físicas, colunas, tipos e índices.
    • Aba SQL: O editor de texto onde digitamos e executamos os comandos CREATE, INSERT e SELECT.
    • Abas Exportar / Importar: Para gerar e restaurar backups de scripts .sql.
  4. Teste de Conexão com o Servidor
    Selecione seu banco no menu lateral, abra a aba SQL, digite SELECT VERSION(), CURRENT_DATE(); e clique em Executar para validar a resposta ativa do MySQL.

4. Guia de Sobrevivência (Conceitos-Chave)

Conceito Significado na Prática
Normalização Conjunto de regras matemáticas que eliminam duplicação e garantem consistência no banco.
1FN (Atomicidade) Garante que nenhum campo armazene listas ou vetores de valores na mesma linha.
2FN (Totalidade da Chave) Impede que colunas dependam apenas de parte de uma chave primária composta.
3FN (Fim da Transitividade) Garante que campos dependam direta e exclusivamente da chave primária (PK).
phpMyAdmin Painel de controle visual baseado em navegador para administração de bases MySQL.
