Materialização Física dos Projetos Integradores — Criando as Tabelas no MySQL

Transformação dos diagramas conceituais (DER/MER) e Dicionário de Dados do Projeto Integrador em scripts DDL físicos, auditoria visual com o Designer do phpMyAdmin e carga de testes com o Prof. Haroldo Curti e Prof. Facine.

1. Checklist Pré-Implementação: Do Papel para o SQL

Hoje é o grande momento de conectar toda a teoria de modelagem ao software real do seu Projeto Integrador. Antes de rodar os comandos CREATE TABLE, valide com sua dupla os 4 pilares estruturais:

Pilar 1
Precedência de Criação

Crie sempre as tabelas independentes (pais) antes das tabelas dependentes (filhas). Nenhuma FK pode apontar para uma tabela inexistente.

Pilar 2
Tipagem Física Precisa

IDs com INT UNSIGNED AUTO_INCREMENT, textos com VARCHAR(100) e valores monetários rigorosamente em DECIMAL(10,2).

Pilar 3
Integridade de Tipos nas FKs

O tipo de dado e atributo da Chave Estrangeira deve ser idêntico ao da Chave Primária referenciada (INT UNSIGNED com INT UNSIGNED).

Pilar 4
Motor & Charset Padrão

Finalize todas as tabelas com ENGINE=InnoDB e banco com CHARACTER SET utf8mb4.

2. Estrutura Padrão do Script DDL do Projeto (banco_projeto.sql)

Utilize o esqueleto profissional abaixo como referência para estruturar o banco da sua equipe:

SQL • Script DDL Padrão de Projeto Integrador MySQL 
SET NAMES utf8mb4;

DROP DATABASE IF EXISTS db_meu_projeto;
CREATE DATABASE db_meu_projeto 
  CHARACTER SET utf8mb4 
  COLLATE utf8mb4_unicode_ci;

USE db_meu_projeto;

-- --------------------------------------------------------------------
-- 1. TABELAS INDEPENDENTES (PAIS)
-- --------------------------------------------------------------------

CREATE TABLE clientes (
    id_cliente INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(120) NOT NULL,
    cpf CHAR(11) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL UNIQUE,
    telefone VARCHAR(20),
    data_cadastro DATETIME DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB;

CREATE TABLE categorias (
    id_categoria INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    nome_categoria VARCHAR(60) NOT NULL UNIQUE,
    descricao VARCHAR(255)
) ENGINE=InnoDB;

-- --------------------------------------------------------------------
-- 2. TABELAS DEPENDENTES (FILHAS)
-- --------------------------------------------------------------------

CREATE TABLE produtos (
    id_produto INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    nome_produto VARCHAR(150) NOT NULL,
    preco DECIMAL(10,2) NOT NULL,
    estoque INT NOT NULL DEFAULT 0,
    id_categoria INT UNSIGNED NOT NULL,
    CONSTRAINT fk_categoria_produto 
        FOREIGN KEY (id_categoria) REFERENCES categorias(id_categoria)
        ON UPDATE CASCADE ON DELETE RESTRICT
) ENGINE=InnoDB;

CREATE TABLE pedidos (
    id_pedido INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    data_pedido DATETIME DEFAULT CURRENT_TIMESTAMP,
    status_pedido ENUM('Pendente', 'Pago', 'Cancelado', 'Entregue') DEFAULT 'Pendente',
    id_cliente INT UNSIGNED NOT NULL,
    CONSTRAINT fk_cliente_pedido 
        FOREIGN KEY (id_cliente) REFERENCES clientes(id_cliente)
        ON UPDATE CASCADE ON DELETE RESTRICT
) ENGINE=InnoDB;

-- --------------------------------------------------------------------
-- 3. TABELA ASSOCIATIVA (N:M - ITENS DO PEDIDO)
-- --------------------------------------------------------------------

CREATE TABLE itens_pedido (
    id_pedido INT UNSIGNED NOT NULL,
    id_produto INT UNSIGNED NOT NULL,
    quantidade INT NOT NULL CHECK (quantidade > 0),
    preco_unitario DECIMAL(10,2) NOT NULL,
    PRIMARY KEY (id_pedido, id_produto),
    CONSTRAINT fk_item_pedido FOREIGN KEY (id_pedido) REFERENCES pedidos(id_pedido) ON DELETE CASCADE,
    CONSTRAINT fk_item_produto FOREIGN KEY (id_produto) REFERENCES produtos(id_produto) ON DELETE RESTRICT
) ENGINE=InnoDB;

3. Auditoria Visual com a Ferramenta Designer

  1. Execução do Script na Aba SQL
    Copie seu script DDL completo, cole na aba SQL do phpMyAdmin e clique em Executar.
  2. Abertura da Ferramenta Designer
    No menu superior do banco de dados, clique em Mais ➔ Designer.
  3. Conferência das Linhas Relacionais
    Organize os cartões das tabelas na tela. Verifique se todas as linhas de chave estrangeira apontam com precisão da coluna de FK para a PK correspondente, confirmando a integridade física do seu Projeto Integrador.
